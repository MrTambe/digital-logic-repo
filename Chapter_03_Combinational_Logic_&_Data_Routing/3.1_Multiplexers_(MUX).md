# 🔀 3.1 Multiplexers (MUX)

A **Multiplexer** (often abbreviated as **MUX**) is a foundational digital circuit that acts as a digitally controlled multi-position switch. Its primary function is to receive multiple input data streams and route exactly one of them to a single output line, based on the binary value of a set of "selector" or "control" pins.

In computer architecture, multiplexers are the ultimate traffic controllers. They dictate which memory bank sends data to the processor, which register feeds into the Arithmetic Logic Unit (ALU), and which peripheral gets access to the main system bus.

Mathematically, a MUX with $n$ selector lines can control up to $2^n$ data inputs.

---

## 🎛️ 3.1.1 Basic 2-to-1 MUX

The 2-to-1 Multiplexer is the smallest possible routing unit. It features two data inputs ($D_0$ and $D_1$), a single selector input ($S$), and one output ($Y$).

      <b>Pros:</b> Universally supported across all hardware and simulators.<br>
      <b>Cons:</b> Higher gate count and non-zero propagation delay.

## 🛣️ 3.1.3 8-Bit Wide Bus MUX

Until now, the MUX has routed single-bit wires (a single `1` or `0`). However, a functional CPU moves data in blocks called **Buses** (e.g., an 8-bit byte, a 32-bit word, or a 64-bit vector).

To choose between routing the 8-bit output of an ALU **OR** the 8-bit output of RAM into a CPU Register, we must use an **8-Bit Wide Bus MUX**.
