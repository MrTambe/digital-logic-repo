# 🟧 2.3 OR Gate (Logical Disjunction)

The **OR gate** performs **Logical Disjunction**—meaning the output is ON (`1`) if **at least one** of its inputs is ON (`1`). The output drops to OFF (`0`) **if and only if** all inputs are simultaneously OFF (`0`).

In digital system design and Sebastian Lague's *Digital Logic Simulator*, the OR gate is the foundational decision-maker. While often provided as a toolbar primitive in digital logic suites, mathematically it can be derived directly from AND and NOT primitives using **De Morgan's Laws**.

## 📐 Component Blueprint

If treated as a built-in simulator primitive, the OR gate responds in a single clock cycle. If constructed from foundational AND/NOT primitives, it incurs a slight propagation delay.

* **Gate Depth (Primitive Mode):** `1 Tick`
* **Gate Depth (Built from NOT/AND):** `3 Ticks`
* **Input Pins:** `2` (Data Inputs `A` and `B`)
* **Output Pins:** `1` (Disjunction Output `Q`)
* **Dependencies:** None (Primitive) or `2× NOT`, `1× AND` (Derived)

## 💡 Practical Hardware Applications

The OR gate plays a dominant role in system-level control logic where multiple independent conditions must be able to trigger a single action:

### 1. Alarm & Safety Interlocks
In industrial controllers or power management circuits, an emergency shutdown must fire if **any** safety threshold is breached:
* Input `A`: Temperature Overheat Sensor (`1` = Critical)
* Input `B`: Voltage Surge Sensor (`1` = Critical)
* Output `Q`: Master Safety Trip Line
* If either sensor reports a fault, $Q = 1$, instantly tripping the circuit breaker.

### 2. Interrupt Request (IRQ) Merging
Modern CPUs have fewer interrupt lines than peripherals. Multiple external hardware devices (keyboard, mouse, network card) route their "data ready" flags through a wide OR gate network to assert a single CPU interrupt signal. If any peripheral needs attention, the CPU is notified immediately.

### 3. Data Bus Combining
In memory controllers, when selecting data sources from multiple register outputs where non-selected sources are held at `0`, an array of OR gates merges the enabled register lines onto a single shared internal data bus.

## 🛠️ Alternative Designs (Universal & Primitive Construction)

Depending on your design constraints or IC availability, an OR gate can be synthesized using several configuration schemes:

### Method 1: Construction from NOT + AND (De Morgan's Law)
By De Morgan's Law, negating the conjunction of two inverted signals produces a logical OR. This is the exact circuit blueprint used if your environment only gives you AND and NOT gates:
* **Equation:** $A + B = \overline{\overline{A} \cdot \overline{B}}$
* **Gate Depth:** `3 Ticks` (1 Tick for input inverters + 1 Tick for AND + 1 Tick for output inverter)
* **Wiring:**
  1. Pass Input `A` into NOT Gate 1 to get $\overline{A}$.
  2. Pass Input `B` into NOT Gate 2 to get $\overline{B}$.
  3. Route $\overline{A}$ and $\overline{B}$ into an AND gate to yield $\overline{A} \cdot \overline{B}$.
  4. Route the AND output into NOT Gate 3 to yield $Q = A + B$.

### Method 2: Using NAND Gates Only
NAND is a universal gate. Constructing an OR gate requires 3 NAND gates:
* **Equation:** $\overline{\overline{A \cdot A} \cdot \overline{B \cdot B}} = A + B$
* **Gate Depth:** `2 Ticks`
* **Wiring:** 
  1. Wire NAND Gate 1 as an inverter for Input `A` ($\overline{A}$).
  2. Wire NAND Gate 2 as an inverter for Input `B` ($\overline{B}$).
  3. Connect $\overline{A}$ and $\overline{B}$ into NAND Gate 3.

<img width="1920" height="838" alt="NAND+OR" src="https://github.com/user-attachments/assets/856ee4e5-8426-43e7-81b3-fe14bb093f95" />


### Method 3: Using NOR + NOT Gates
A NOR gate is simply an inverted OR gate ($\overline{A + B}$). Adding a NOT gate directly after it restores the original OR functionality.
* **Equation:** $\overline{\overline{A + B}} = A + B$
* **Gate Depth:** `2 Ticks` (1 Tick for NOR + 1 Tick for NOT)

## 🌲 Scaling Multi-Input OR Gates

When designing instruction decoders or multi-bit status aggregators, you frequently need to check if *any* bit across an 8-bit or 16-bit word is set to `1`.

Linear Cascade Chain (High Delay)          Balanced Binary Tree (Optimized)

Input A ──┐                                Input A ──┐
          ├──[ OR ]──┐                     Input B ──┴──[ OR ]──┐
Input B ──┘          │                                          ├──[ OR ]── Output Q
Input C ─────────────┼──[ OR ]──┐          Input C ──┐          │
                     │          ├── Output Input D ──┴──[ OR ]──┘
Input D ─────────────┴──────────┘



### Strategy A: Linear Cascade Chain (High Latency)

Connecting 2-input OR gates in a continuous series line.

* **Gate Depth for N Inputs:** $N - 1$ Ticks
* **Impact:** For a 16-input OR operation, propagation delay reaches **15 Ticks**. This slow signal path creates long timing delays before the CPU can determine conditional jump flags.

### Strategy B: Balanced Binary Tree (High Speed)

Arranging OR gates in logarithmic parallel stages.

* **Gate Depth for N Inputs:** $\lceil \log_2(N) \rceil$ Ticks
* **Impact:** A 16-input OR tree resolves in just **4 Ticks** ($2^4 = 16$), providing a **3.75x speedup** over the linear cascade and ensuring stable high-frequency clock performance.
