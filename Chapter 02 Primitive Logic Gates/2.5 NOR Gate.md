# 🟥 2.5 NOR Gate (Negated OR)

The **NOR gate** (short for Not-OR) performs the exact opposite function of an OR gate. It outputs ON (`1`) **if and only if** all of its inputs are completely OFF (`0`). If *any* input is turned ON (`1`), the output immediately drops to OFF (`0`).

Alongside the NAND gate, the NOR gate is the second **Universal Gate**. This means you can build any digital component—from a simple memory flip-flop to an entire microprocessor—using absolutely nothing but NOR gates wired in different configurations.

## 📐 Component Blueprint

In Sebastian Lague's *Digital Logic Simulator*, building a NOR gate from scratch requires appending a NOT gate to the output of your custom OR gate. Because the OR gate itself is built from 3 primitives (if you aren't using the built-in OR chip), the latency stacks up.

* **Gate Depth:** `4 Ticks` (3 Ticks for OR + 1 Tick for NOT) *or* `2 Ticks` if using a pre-packaged OR chip.
* **Input Pins:** `2` (Data Inputs `A` and `B`)
* **Output Pins:** `1` (Negated Disjunction Output `Q`)
* **Dependencies:** `1× OR`, `1× NOT`

## 💡 Practical Hardware Applications

While NAND dominates bulk storage, the NOR gate holds its own legendary status in both history and specific modern memory architectures:

### 1. The Apollo Guidance Computer (History)
The computer that successfully navigated the Apollo 11 spacecraft to the moon in 1969 was built almost exclusively out of 3-input NOR gates. NASA engineers chose to use a single universal gate type (using roughly 5,600 logic gates in total) to maximize reliability and standardize manufacturing during the space race.

### 2. NOR Flash Memory (Firmware & BIOS)
Unlike NAND flash (which reads data in large blocks), NOR flash memory allows for true random byte-level access. Because the CPU can read individual bytes directly from a NOR chip just like RAM, it is universally used for Execute-In-Place (XIP) firmware, computer BIOS chips, and embedded microcontroller systems where fast, reliable code execution is critical.

## 🛠️ The Power of Universality (Building Other Gates)

Just like the NAND gate, you can prove the NOR gate is universal by using it to recreate the three base functions of digital logic:

### 1. Building a NOT Gate from NOR
By splitting a single input signal so it drives both input pins of a NOR gate, it acts as a perfect inverter.
* **Equation:** $\overline{A + A} = \overline{A}$
* **Requirement:** `1× NOR Gate`

### 2. Building an OR Gate from NOR
Since NOR is just an inverted OR, passing its output through a second NOR gate (wired as a NOT gate) flips the signal back to a standard OR function.
* **Equation:** $\overline{\overline{A + B}} = A + B$
* **Requirement:** `2× NOR Gates`

### 3. Building an AND Gate from NOR (De Morgan's Law)
By inverting both input signals before they reach the main NOR gate, you transform the disjunction into a conjunction.
* **Equation:** $\overline{\overline{A} + \overline{B}} = A \cdot B$
* **Wiring:** 
  1. Invert Input `A` using a NOR gate.
  2. Invert Input `B` using a NOR gate.
  3. Feed both inverted signals into a third NOR gate.
* **Requirement:** `3× NOR Gates`
