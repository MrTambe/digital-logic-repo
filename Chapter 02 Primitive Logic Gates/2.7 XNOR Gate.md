# 🟦 2.7 XNOR Gate (Exclusive NOR / Equivalence)

The **XNOR gate** (short for Exclusive NOR, sometimes called an **Equivalence Gate**) performs a strict equality check. It outputs ON (`1`) **if and only if all inputs are identical**. If the inputs differ from one another, the output drops to OFF (`0`).

Mathematically and structurally, the XNOR gate is simply an inverted XOR gate. Where the XOR gate highlights difference, the XNOR gate highlights similarity, making it the premier building block for digital comparison operations in hardware.

## 📐 Component Blueprint

In Sebastian Lague's *Digital Logic Simulator*, you can easily build an XNOR gate by attaching a NOT gate to the output of your previously designed XOR chip.

* **Gate Depth:** `~4 to 6 Ticks` (Depends on internal XOR design + 1 Tick for NOT inverter)
* **Input Pins:** `2` (Data Inputs `A` and `B`)
* **Output Pins:** `1` (Equivalence Output `Q`)
* **Dependencies:** `1× XOR`, `1× NOT` (or built from `AND`, `OR`, `NOT` primitives)

## 💡 Practical Hardware Applications

The XNOR gate's ability to act as a hardware equality comparator is essential across several compute components:

### 1. Digital Magnitude Comparators (`A == B`)
To check if two binary numbers are equal (for example, comparing two 8-bit registers $A$ and $B$), you pass each corresponding bit pair ($A_0$ with $B_0$, $A_1$ with $B_1$, etc.) through an XNOR gate. The outputs of all 8 XNOR gates are then fed into an 8-input AND gate. If every single bit pair matches, the final AND gate outputs `1`, signaling that $A == B$.

### 2. Cache Hit Logic in CPUs
Modern processors rely on high-speed cache memory. When a CPU requests a memory address, a hardware comparator uses arrays of XNOR gates to instantly compare the requested address against the tags stored in the cache lines. A match across all bits triggers a "Cache Hit," allowing data retrieval in a fraction of a nanosecond.

### 3. Even Parity Detectors
While XOR gates count whether an odd number of inputs are set to `1`, cascading XNOR gates checks for **even parity** (detecting whether an even number of bits are high). This is a critical building block in error-detection networks for communication buses.

## 🛠️ Internal Circuit Designs

If you prefer to build an XNOR gate directly without first placing a standard XOR chip, you can use these direct topologies:

### Method 1: Direct Sum-of-Products (AND, OR, NOT)
This implementation maps to the boolean expression: "Output is ON if BOTH inputs are ON, OR if BOTH inputs are OFF."
* **Equation:** $(A \cdot B) + (\overline{A} \cdot \overline{B})$
* **Wiring:**
  1. Route `A` and `B` into **AND Gate 1** (yields $A \cdot B$).
  2. Invert both `A` and `B` using NOT gates, then route them into **AND Gate 2** (yields $\overline{A} \cdot \overline{B}$).
  3. Route the outputs of both AND gates into an **OR Gate**.

### Method 2: The 5-NAND Construction
To build an XNOR using exclusively universal NAND logic, you add one additional inverter NAND stage to the standard 4-NAND XOR layout.
* **Equation:** $\overline{\text{XOR(A, B)}}$
* **Requirement:** `5× NAND Gates`
