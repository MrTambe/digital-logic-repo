# ➕ 4.1 Half Adders

A **Half Adder** is the simplest and most fundamental digital arithmetic circuit. Its primary function is to add two single-bit binary numbers ($A$ and $B$) together. 

When you add two binary bits, the result can range from `0` to `2` (in decimal). Because binary can only represent a maximum of `1` in a single column, an addition that results in `2` (binary `10`) requires two output wires: one for the **Sum** ($S$) and one for the **Carry** ($C$) to pass the overflow to the next column.

It is called a "Half" Adder because it lacks the ability to accept a "Carry-In" signal from a previous addition. This limitation restricts it to adding only the very first (least significant) column of a multi-bit number.

## 🛠️ 4.1.2 Hardware Implementation

Because the Boolean logic simplifies so elegantly, constructing a Half Adder at the transistor or gate level is incredibly efficient. It requires exactly two logic gates running in parallel.

      <b>Wiring Steps:</b>
      <ol>
        <li>Split input wire $A$ into two parallel paths.</li>
        <li>Split input wire $B$ into two parallel paths.</li>
        <li>Connect one pair of $A$ and $B$ directly into an <b>XOR Gate</b>. The output of this gate is your <b>Sum ($S$)</b> wire.</li>
        <li>Connect the second pair of $A$ and $B$ directly into an <b>AND Gate</b>. The output of this gate is your <b>Carry ($C$)</b> wire.</li>
      </ol>
      <b>Gate Depth (Delay):</b> <code>1 Tick</code><br>
      Both the Carry and Sum are generated simultaneously. There is no waiting for one gate to finish before another starts.<br><br>
      <b>Component Cost:</b> Very low (1 XOR, 1 AND).

      <br><br>
      <i style="font-size: 0.9em;">Column 1 generates a Carry, but Column 2 has nowhere to plug it in!</i>
    </td>
    <td align="left" valign="top" style="padding: 10px; font-size: 0.95em;">
      <b>The Core Issue:</b><br>
      If you want to add two 4-bit numbers together (e.g., `1011 + 0111`), you cannot simply place four Half Adders side-by-side. 
      <br><br>
      When the first column calculates `1 + 1`, it outputs a sum of `0` and a Carry of `1`. The second column needs to add its own two inputs <i>plus</i> the Carry from the first column. A Half Adder only has two input pins ($A$ and $B$)—it is completely blind to carries coming from the right.
      <br><br>
      <b>The Solution:</b><br>
      To build multi-bit calculators, we use the Half Adder strictly for the 0th bit, and upgrade to a <b>Full Adder</b> (which has an $A, B$, and $Carry_{IN}$ pin) for all subsequent columns.
    </td>
  </tr>
</table>
